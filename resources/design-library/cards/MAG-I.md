# I｜偏置静物与有重量的彩色留白

## 图例与证据范围

实际查看：参考图例 MAG-I（本机资源 `MAG-I-preview`）。与网页包同名图字节一致。原包标注摄影 Pim Top、艺术指导 Cameranesi Pompili、设计 Erin Knutson，归属与[档案链接](https://archive.pinupmagazine.org/articles/special-edition-cover-sunflowers-pim-top)均作原包元数据保留，本轮未访问外部页面。红色纸页之外的黑色区域是展示背景。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 通栏黑色大刊头提供识别，右侧照片中的黄色花朵与台面构成鲜明焦点；蓝色花瓶进一步聚焦物件。左侧大面积红色则把注意力留给右侧静物。 |
| 对齐 | 标题靠近纸页上边并横贯宽度；静物图右置，右边和下边保留窄边距。图下小署名跟随图片，左侧简介与短词形成另一组信息。 |
| 字号关系 | 刊头极大、黑重且简洁；简介、短词、摄影署名及条码退到很小层级。没有用次级大标题填满左侧空区。 |
| 文字与主体 | 照片保持清晰矩形边界，花朵和花瓶在框内完整展示；文字主要在图外，不与静物细节争空间。 |
| 负空间 | 左侧红色区域虽然内容少，视觉上仍有重量；它与右侧细节密集的照片共同平衡画幅。它不是可随意塞入多行介绍的空位。 |
| 色彩关系 | 红纸与照片中的深红背景相接近，图片又靠黄色底面、花朵和蓝瓶与外部区分。关联和对比同时存在，不是单纯把图片贴到任意色块上。 |

## 可复用设计逻辑

用“有色的空白”与偏置照片共同构图。图片外部背景可以响应图片自身的色彩，同时保留边界；这让静物成为有重量的视觉对象，而不是依赖满版裁切才显得重要。

适用：家具、灯具、花艺、酒瓶、艺术品等单体细节页；也可用于项目的关键材料或陈设章节。需要解释完整房间关系时，应先给全景，避免把孤立物件当成空间全貌。

## 跨端适配

- **PPT：**可将独立照片放在右侧或左侧，另一侧用于短标题与必要说明；图片、标题与图注分别可编辑。长说明应有自己的阅读区，不以“参考本来留白”拒绝必要信息。
- **网页：**桌面允许偏置图幅；手机把图和说明按顺序展开，保留色彩呼应但调整空白体量。不要因左侧空白在窄屏变窄，就把文字压到图片内部。

迁移时建议保留：①图片清楚的矩形边界；②彩色留白与主体的平衡；③图注依附真实对象。允许变化：①背景色；②图像的左右位置和占幅。

## 不应机械照搬

不复制刊名、价格、条码或艺术家署名到新项目；不固定正红色；不将图外黑背景当作封面边框；不默认把真实家具改色来呼应版面。

## 调用时的核对问题

背景色是否与源图有可解释的关系？图片偏置后重心是否稳定？空白是在衬托物件，还是让关键说明丢失？

原始图例不随仓库分发。本记录的实际看图发生于本机；没有本地素材的协作者只能阅读研究记录。
