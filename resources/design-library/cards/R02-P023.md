# R02-P023｜材料近景与空间主图建立对应说明

来源：R02，物理第 23 页。原件 `R02-original`；预览 `R02-P023-preview`。

## 实际观察

- **visible_content**：深色背景上，左侧两幅高图表现晶体反光和浅色石材纹理；右上是空间图，右下是一组较小的纹理、光线和晶体图。下部有空间材质分析页名。
- **image_text_roles**：左侧近景突出材料表面，右上大图提供空间语境；正文和小标题置于右下黑色矩形区，面积明显小于图组。
- **grid_alignment**：内容集中在中部横带，左双图共用顶底边；右上主图与下方小图带共享总宽；顶部与底部保留大段深色空区。
- **whitespace**：深色空区承担外边距，图组内部间隙很窄；不能把深底自动理解为没有留白。
- **typography**：小标题为浅色英文、外有细框，中文说明较小；底部页名居中。未核验字体家族和准确字号。
- **density_and_crop**：图像密度高，材质图为局部取景，空间图只显示局部大厅；无原始图片对照，无法判定裁切比例。浅色小字可部分辨读但不适合直接缩放套用。

## 设计推导

- **reading_order**：视觉可能先落在浅色材料近景，再进入右侧空间主图，最后读材料说明；主次由亮度、面积和尺度共同建立。
- **reusable_rules**：先给材料视觉特征，再展示它如何影响空间，不把一组不相关纹理当成材料逻辑。；材料近景、空间结果、文字解释是不同角色，排版时分别标记。；深底页的正文与投影亮度必须验证，不能只看电脑缩略图。
- **suitable_for**：有空间应用证据的材料说明；少量主材与光线的组合；概念到空间的过渡页
- **avoid**：把近景当真实规格；多个空间与许多材料全部塞入同一页；黑底低对比小字直接继承
- **ppt_workflow_change**：页面计划新增material_intent类型，要求提供主材图、空间图及明确对应理由；缺空间对应时只标材料意向，不能称已落地。

## 范围与限制

- 材料型号、性能和空间实施状态未核验。
- 左上低对比三横线仅可见为图形，不确认是否具有交互功能。
- 仅查看物理第23页，未核验本册完整概念链条。

未核实字体家族、精确字号及对外资产复用授权。设计推导不代表原作者意图或用户已认可。原图不随仓库分发。
