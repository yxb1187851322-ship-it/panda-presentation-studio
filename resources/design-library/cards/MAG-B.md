# B｜建筑水平轴与轻量角落标注

## 图例与证据范围

实际查看：参考图例 MAG-B（本机资源 `MAG-B-preview`）。与网页包同名图字节一致。原包目录记录为 206–207 页及[期刊来源](https://thelocalproject.com.au/product/issue-19/)；本图不足以独立确认页码，外部来源页本轮未访问。灰色桌面、书脊阴影与纸张弯曲属于实物展示，不是版面结构。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 建筑长屋面与玻璃立面形成最强的横向带状焦点。上下较平静的浅色天空和地面把立面托在画幅中部，观看可沿屋面、柱列和植栽横向移动。 |
| 对齐 | 两个短白字分别位于跨页底部左、右角，距底边接近；建筑的水平线主导秩序，文字只作边缘锚点。 |
| 字号关系 | 图像占绝对主导，两个短标注体量接近且都很轻。没有额外的巨型标题去争抢立面。可见为简洁无衬线特征，不能据图猜具体字体。 |
| 文字与主体 | 字落在前景平静地面，避开玻璃、植栽及屋面边界。左右标注与画面共同横向展开，而不是压在空间中央。 |
| 负空间 | 天空和前景地面是照片内的空间缓冲；书外灰背景没有编辑信息功能。上方天空与下方地面作用不同，不能简单认作必须等宽的上下白边。 |
| 真实边界 | 图像跨过书脊，但纸页弯曲导致中线变形。这不应迁移成网页中央的阴影或PPT折页效果。 |

## 可复用设计逻辑

让建筑本身的水平线、柱列或透视建立顺序，再把少量识别信息放在不会切断这些结构的平静角落。图像占主导并不意味着没有排版：两端标注与清晰的底边关系提供了阅读入口和收束。

适用：建筑外观、酒店大堂或连续公共空间的完整展示、项目总览和章节主图。前景复杂、地面明暗变化大或文字必须较多时，应给文字独立区域。

## 跨端适配

- **PPT：**优先保留屋面、立面及必要前景的整体关系，文字独立可编辑。横屏适合这种延展，但仍按实际源图比例取景；信息更多时另起技术页，不把说明塞进两个角落。
- **网页：**桌面可保留宽幅。手机若直接满屏裁为竖图会丢失建筑两端，可用完整宽图配图下标题，必要时另给有出处的细节图或可访问的查看入口。不要把超宽图缩到看不清后仍称已完整呈现空间细节。

迁移时建议保留：①空间关键几何与轴线；②图像优先；③短标注沿边缘安置。允许变化：①标注在图内或图外的位置；②照片与画布的占比。

## 不应机械照搬

不复制“Paloma”“Fearon Hay”；不把书外灰色背景和书脊阴影算作排版；不强求所有文字都白色；不为塞满画幅拉伸建筑，不因竖屏而静默裁掉关键空间。

## 调用时的核对问题

哪些建筑边界必须完整？地面是否真的能承载文字？手机显示的是整体概览还是局部细节？两种功能应分别有清楚的视觉证据。
