# J｜巨型文字背景与主体前置穿插

## 图例与证据范围

实际查看：参考图例 MAG-J（本机资源 `MAG-J-preview`）。与网页包同名图字节一致。影片归属及[原包来源](https://a24films.com/films/the-green-knight)沿用原包目录，外部网页本轮未访问。工具显示时缩小了长图，不据此推断精确字号或完整演职员信息。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 大片黄色文字与红底先形成强冲击；前方人物和举起的斧头打断字块，斧柄及披风的斜线使视线从左下向右上或沿动作来回移动。 |
| 对齐 | 主标题分成上下堆叠的大字块，整体近中轴；不同单词行宽不同，形成扩张的轮廓。底部地面是共同落脚边界，其他小字集中在上沿和下沿。 |
| 字号关系 | 主标题巨大、厚重且偏窄，成为背景形状；导演信息次之；底部说明极密。原图字形有个性切角，不能由肉眼指定某款字体或把任意字体压窄代替。 |
| 文字与主体 | 主体在标题前方，部分字被遮挡但整体词形仍可推读。人物、手、斧与披风轮廓清楚，脚下有实体地面，使遮挡关系成立。 |
| 负空间 | 红色边缘、字内空隙及人物周围的红底提供间隔；几乎没有传统大留白。秩序来自单一巨型文字组与单一主角。 |
| 色彩与深度 | 黄字、红底与较暗人物形成明确前后层级；地面暗带承接人物和底部信息。颜色越强烈，信息层级越需要单纯。 |

## 可复用设计逻辑

当标题本身是核心信息且主体轮廓清楚时，文字可以成为背景建筑般的体量，主体再以局部遮挡建立前后关系。其前提是“被挡后仍能识别”与“主体有真实着力点”，而不是单纯把字无限放大。

适用：明确追求宣传冲击的主视觉、发布活动、展览或短主题开场。设计事实、图纸尺寸和详细方案说明不宜作为被遮挡的大字背景；普通空间全景也不应默认做抠图穿插。

## 跨端适配

- **PPT：**可在用户授权的真实素材条件下使用独立主体图与原生标题形成前后关系。中文词形更密，应重新判断字数与遮挡程度；保持必要项目名可读。没有可用分层素材时用图文并置，不能假称已获得可编辑主体层。
- **网页：**桌面和手机分别确定文字换行与主体位置；提供一份语义完整的标题，不让视觉拆字破坏朗读顺序。若使用滚动变化，必须验证遮挡中间状态与减少动态模式；静态画面也能完成核心任务时不必添加动画。

迁移时建议保留：①标题与主体明确的前后层级；②轮廓及落脚关系；③少量主色与集中信息。允许变化：①文字体量与分行；②配色与主体位置。

## 不应机械照搬

不复制电影标题、台词、演职员和发行信息；不强制红黄配色；不为穿插效果擅自抠走建筑构件或遮住重要参数；不把巨大英文的字形面积关系直接套到长中文项目名。

## 调用时的核对问题

被挡住后标题是否仍清楚？主体是否有明确完整的边界？这个主题真的需要宣传强度吗？剔除装饰性巨字后，事实信息是否仍完整存在？

原始图例不随仓库分发。本记录的实际看图发生于本机；没有本地素材的协作者只能阅读研究记录。
