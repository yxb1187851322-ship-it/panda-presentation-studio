# R00-P062｜基准图与四个变体共页比较

来源：R00，物理第 62 页。原件 `R00-original`；预览 `R00-P062-preview`。

## 实际观察

- **page_purpose_visible**：左上为标题与小黑底标签，左中为一幅较小的室内图，左下为短说明；右侧四幅室内图组成两行两列。
- **image_text_roles**：左侧小图与文字构成解释区，右侧四图获得主要面积。图片之间在家具、壁炉、开窗等构图上存在可见差异。
- **grid_alignment**：左区约四分之一宽；右区为2×2图阵，行列边界一致，窄白缝把四图分开。标题与右图组上沿大致齐平。
- **whitespace**：左区各元素间有显著间隔；右侧空间主要留给画面，外边距小于左区内部空隙。
- **typography**：中文标题粗重，正文较轻且灰度较浅，小黑底标签形成紧凑次级标识。准确字体未能判定。
- **information_density**：视觉信息高、文字低；四个大图没有明显逐项编号或单独差异说明。
- **image_crop**：四个大图使用相同矩形框，主体家具均保留；原图尺寸和裁切范围未知。不同视角不能自动当成严格同条件对照。

## 设计推导

- **reading_order**：先读主题与左侧基准，再扫读四个变体；没有编号时，具体比较顺序并不唯一。
- **reusable_rules**：保留基准图，使变体有参照。；同一比较维度的图保持同框比例，并标明真正变化的部分。；需要用户选择时增补A/B/C/D和差异摘要，不能只让用户猜图片差别。
- **suitable_for**：2至4个空间方向比较；材质或家具变体；视觉实验记录
- **unsuitable_for**：严谨技术比对但机位不同；各图都需长解释；把意向图直接当已实施成果
- **media_adaptation**：网页可用同一基准下的切换比较；手机每次显示一个方案及其差异；杂志可保留四宫格，但小字和标签需独立校准。
