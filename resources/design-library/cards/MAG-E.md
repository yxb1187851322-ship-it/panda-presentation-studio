# E｜独立刊头与室内摄影纵向分层

## 图例与证据范围

实际查看：参考图例 MAG-E（本机资源 `MAG-E-preview`）。与网页包同名图字节一致。名称和期号沿用原包记录及图中可见信息；[原包所列来源](https://openhouse-magazine.com/shop/product/issue-no24/)本轮未访问。工具显示本图时做了尺寸适配；本轮研究版面关系，没有将底部细字当作已精确转写的全文。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 上部白色区域的大黑刊头首先建立识别；向下是墙上横向排列的小画，再到右下两把椅子，最后落到照片底部的短文。 |
| 对齐 | 刊头在独立的白色横带中，照片宽度与白带一致。墙面横线、画框阵列和地面边界强化水平秩序；椅子偏右，避免主体与刊头都完全居中。 |
| 字号关系 | 刊头远大于期号、主题和底部介绍。底部多行文字具有不同于刊头的细小字形与紧凑节奏，但不能据图确认精确字体。 |
| 文字与主体 | 刊头没有侵入室内摄影。小型期号/条码使用左上墙面，正文利用下部地面；它们虽能安置，却并不证明这种小字叠图适合数字屏幕。 |
| 负空间 | 白色刊头区是明确的纸页设计；墙面空区是摄影内的空白；外部米色背景与投影是展示环境。三者性质不同。 |
| 主体分布 | 画框和椅子的间距、墙脚水平线与地面形成层次。照片的右侧重量由左侧空墙平衡，不需要把椅子拉到中央。 |

## 可复用设计逻辑

把品牌或项目识别与摄影分区，能让标题保持稳定可读，也让室内画面保持完整。版式的克制来自信息各归其位：刊头负责识别，摄影负责空间感，正文负责解释。其内部仍存在非对称的主体分布，而不是每个元素都居中。

适用：酒店、住宅、会所等专题封面或单项目介绍；尤其适合图片顶部不适合落字、但项目名称需要稳定识别的情形。信息量较大时应把说明从照片底部移出。

## 跨端适配

- **PPT：**横屏可借用独立标题带或侧栏，将真实项目名与照片分区。标题带的厚度由文本与图片决定，不应把竖版封面等比缩成横屏中央一小张。说明使用原生文本，可另起正文页。
- **网页：**标题、图片和介绍采用真实的连续结构。手机把底部多行文字置于独立正文区，避免压在地面纹理上。刊头高度应与首屏信息任务匹配，不必复制封面白带的视觉占比。

迁移时建议保留：①识别区与摄影区的明确边界；②室内主体的完整关系；③刊头、主题与说明的职责分工。允许变化：①标题带方向和厚度；②正文在图内或图外的位置。

## 不应机械照搬

不复制刊名、期号、条码及原刊段落；不把外围米色当作项目默认背景；不照搬小字叠在复杂地板上的处理；不为保留白带比例压缩或拉伸摄影。

## 调用时的核对问题

标题是否需要独立稳定的识别区？摄影原有空墙是否必须保留以支撑空间感？去掉期号与条码后，剩余内容是否仍是本项目需要的信息？
