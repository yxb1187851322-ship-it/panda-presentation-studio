# C｜局部图像与有方向的纸面留白

## 图例与证据范围

实际查看：参考图例 MAG-C（本机资源 `MAG-C-preview`）。与网页包同名图字节一致。原包将其归于[Studio Faculty 案例](https://www.studiofaculty.com/work/cereal-magazine)，具体期号未确认；外部来源页本轮未访问。本图是错落纸页的局部实拍，不是一张完整展开版面，因此不能从照片整体反推精确网格或每页完整图文对应。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 大面积浅灰纸面先降低信息密度，左下较暗照片成为视觉停靠点；右侧可见的多条纸页边界和分散短图注让观看沿竖向与横向继续。 |
| 对齐 | 左侧斜体短词与其右侧两行说明大致处于同一水平区域；各组产品说明各自左对齐。右侧文字的阶梯位置同时受到叠页展示影响，不能认作一个统一网页布局。 |
| 字号关系 | 情境词采用轻量斜体特征；对象名称与作者说明是小型大写无衬线特征，行距清楚。字号相近而角色有别，层级并不依赖巨大的标题。 |
| 文字与主体 | 可见照片只占左下局部；文字与照片分开，纸面本身参与组织信息。当前局部不足以证明每条图注对应哪个完整物件。 |
| 负空间 | 空白集中在左上和图注之间，形成较大的连续区域，而非四周平均留边。它让读者在细节观看中放慢速度。 |
| 实物因素 | 右侧窄暗条、纸厚与错位属于书页实拍。不能直接解释为刻意添加的分隔线或数字界面的滚动分栏。 |

## 可复用设计逻辑

用观看距离与图幅大小制造节奏：一张局部细节可以用较小的占幅承载，同时让名称、材质或来源清楚地依附该内容单元。空白应形成有方向的形状，而不是套用同一圈大边距。此例也提醒：参考证据只到局部，就只能借局部关系。

适用：材质、灯具、器物、家具工艺等细节章节；适合在全景之后形成阅读停顿。不适合必须一眼解释完整空间关系的总览页，也不适合靠大量空白掩盖信息缺失。

## 跨端适配

- **PPT：**可让细节照片偏一侧或偏下，图注按真实归属与图片建立一条清楚的对齐轴；会议展示时把纸刊小字提高到实际观看可读的层级。不要复制叠页实拍当作可编辑页面。
- **网页：**每张图片与其图注成为相邻语义单元，手机按阅读顺序堆叠。保留段落间的停顿，但减少会迫使用户无意义长滑的超大空白；图注保持可读字号，不模拟纸刊缩略图。

迁移时建议保留：①细节图与总体叙事的节奏差；②图注的明确归属；③集中而有方向的留白。允许变化：①图片占幅；②情境词与说明的字体角色、上下位置。

## 不应机械照搬

不复制书页错位、暗边或实物质感；不把右侧多个标签照搬为无来源的家具清单；不猜期号、字体或完整版心；不把“留白多”变成所有项目的唯一标准。

## 调用时的核对问题

空白让哪一项内容更清楚？图注是否有真实对应对象？手机上的空白仍帮助阅读吗？若只有这张局部参考，完整页面结构必须另行设计并验证。
