# A｜人物投影与底边分置标题

## 图例与证据范围

实际查看：参考图例 MAG-A（本机资源 `MAG-A-preview`）。本图与网页包同名图字节一致，只审阅此份。原包目录将其标注为 50–51 页跨页，并记录[期刊来源](https://www.kinfolk.com/product/issue-46/)；页码在图中可见，外部来源页本轮未访问。图片外侧白色展示区域不计入跨页版心。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 右上偏中的浅色人物与大块黑色投影形成第一组焦点；投影向左上延伸，人物身体斜向左下。底部两组白色大字把观看范围拉回整个横向画幅。 |
| 对齐 | 左上小署名与左下标题都靠近左侧安全边；右下标题靠近右侧安全边。两段姓名共用一条底部基线，中间让开人物和跨页接缝。 |
| 字号关系 | 标题是高对比、细粗变化明显的衬线特征大字；署名和页码极小。尺度反差清楚，但精确字体、字号与字距无法由此图确认。 |
| 文字与主体 | 大字利用人物下方及左侧区域，没有压住脸和上身；右侧标题接近脚部下缘，二者形成紧密但可辨的关系。 |
| 负空间 | 左半幅不是白纸，而是信息稀疏的红褐渐暗背景。它容纳署名与姓名，平衡右侧人物和投影的重量。 |
| 色彩与层次 | 红褐背景、黑影、浅色服装及白字构成少量明暗层级。投影是图中叙事的一部分，不能据此要求所有人物图加同样的影子。 |

## 可复用设计逻辑

先检查主体、投影或空间背景在画面中占据哪一侧，再让标题沿剩余的平静边缘建立横向秩序。少字可以有较大的体量，但大字的两端位置必须服务画面平衡。此例的张力来自“密集主体与疏朗背景”以及“上部小字与底部大字”的两组关系，不来自固定的红色或某个字体名称。

适用：人物访谈扉页、设计师介绍、人与空间关系明确的章节开场；也可用于主体集中一侧且背景有足够连续色域的空间照片。主体满幅、底部有必须展示的家具或细节时不宜硬套。

## 跨端适配

- **PPT：**保留主图的完整姿态与投影关系，以原生文本放置标题。可以将长标题拆为两个语义完整的部分，但不能为了左右对称切断中文词组。若横屏裁切伤到人物，改为图文分区或保留图片比例。
- **网页：**桌面可借用底边两端的布局；手机优先完整标题与人物可见性，标题可移到图下或变为单侧短行。不要让左右两段标题在窄屏上割裂阅读顺序。

迁移时建议保留：①真实主体与投影的关系；②标题与主体互相让位；③大标题与小型来源信息的层级。允许变化：①背景色及字体候选；②标题的拆行和所在边缘。

## 不应机械照搬

不复制姓名、刊物署名和页码；不把外部白框当作设计留白；不从这张图推断所有项目都应使用暖棕色与衬线字；不为匹配参考虚构投影、改变人物姿态或遮住事实信息。

## 调用时的核对问题

标题所在背景是否连续可读？主体的脸、手、脚与关键投影是否完整？拆行后语义能否连续理解？长文案若无法容纳，应拆页或另设正文区，不能只缩小字。
