# D｜高彩度现场与黑白文字图形对置

## 图例与证据范围

实际查看：参考图例 MAG-D（本机资源 `MAG-D-preview`）。与网页包同名图字节一致。原包记录为 FRAME 161，并给出[经销商展示来源](https://www.raandollyltd.com/design-interiors/frame)；此来源非刊物官网，本轮未访问。实际图为打开的书，外侧蓝色背景与投影均在版面之外。

## 画面观察

| 维度 | 实际可见关系 |
| --- | --- |
| 视线 | 左页洋红、红桌与蓝衣人物构成彩色视觉密区；右页大面积黑色重复字块与其对抗。先感受两区的重量，再读右页底部的小段说明。 |
| 对齐 | 左页照片近乎铺满纸页，中央书脊自然分开两个区域。右页重复字形成紧凑矩形，上下与左右边界较明确；说明位于字块下方，行宽明显收窄。 |
| 字号关系 | 重复标题极粗、紧凑，部分方向倒转，已承担图形角色。正文、署名与页码退到很小的层级。不能因为标题有实验性就让解释文字也难读。 |
| 文字与主体 | 文字图形主要占右页，人物操作与色彩物件留在左页；二者由并置关联，不靠把大字压到人的脸或手上。 |
| 负空间 | 右页白色边缘与底部区域包围黑字，形成可读的外形；左页视觉密度高，几乎不提供落字区。两边密度不同而视觉重量接近。 |
| 色彩与秩序 | 左页让现场色彩带头，右页只用黑白建立强形。蓝色展示背景与版内高彩度有关联，但不属于可直接迁移的画布配色。 |

## 可复用设计逻辑

当照片本身高度复杂且有强烈色彩时，可给标题一个独立的几何区域，通过图文并置建立同等分量。标题可以像图形一样参与叙事，但仍须有正常阅读的项目名与说明作为入口。

适用：艺术工作室、展览、装置、创作者专题、需要鲜明编辑语气的章节开场。常规施工审阅或材料参数页不应沿用反转标题与重复文字。

## 跨端适配

- **PPT：**可借左右对置，标题与说明保留独立对象。按照真实标题长度决定是否重复、拆行或仅用一次；确保讲解者与观众能立即识别项目。图片与文字区不必固定对半。
- **网页：**桌面可并排；手机把正常可读的标题、主图、说明按语义排序，再决定是否保留装饰性重复。装饰重复不应造成屏幕阅读器反复朗读，也不能靠旋转滚动强迫用户解码标题。

迁移时建议保留：①复杂摄影与简洁文字区的对照；②标题与正文明确分工；③图文重量平衡。允许变化：①左右顺序与比例；②重复、旋转等装饰手段的保留程度。

## 不应机械照搬

不复制“Mestiz”标识或实物书效果；不将每个项目名强行重复五行；不因参考用了倒字就牺牲关键内容识读；不把展示背景蓝色当作规定色。

## 调用时的核对问题

去掉重复与倒转后，核心标题是否仍有力量？重复是否有本项目的语义理由？图文两区是在互相支撑，还是同时争夺主角？
