# Panda 汇报与内容编排 · 本地交互原型

直接用现代浏览器打开 `index.html`。单个 HTML 已包含样式、脚本与几何示意，不需要安装依赖、启动服务、联网或输入密钥。

这是 Panda 现有本地客户端内新增模块的交互讨论稿，不是重新制作官网，也不是正式客户端 UI。所有名称、说明、图片框和几何关系都是演示内容，不是用户真实项目或 CAD 结果。

## 可以体验

- 同一内容切换 PPT、网页、杂志图片，观察三种阅读组织方式。
- 切换项目概述、方案对比、平面说明，查看不同页任务和设计理由。
- 切换品牌锁定标记，体验固定元素与可变内容区的区别；不涉及真实品牌授权。
- 使用“少字版”“完整图框”预设修改，并在三种媒介中查看共享状态。
- 输入一句意见，仅临时加入演示对话；自由输入不会被模型理解或执行。
- 还原演示。刷新浏览器也会清空全部临时状态。

## 未实现的能力

没有文件选择、上传、解析、模型调用、CAD 读取、真实生成、导出、下载、账号、项目持久化或客户端接入。上传和导出按钮明确禁用，不会模拟成功。

网页选项是“用户项目展示网页”的内容结构示意，不代表 Panda 网页客户端或产品官网。页面内图片框为 CSS 几何占位，平面为内联 SVG 几何关系示意，不是生成图片素材，也不含真实尺寸或可施工结论。

正式接入后，素材入口计划接受图片、文档、Logo、固定模板及 CAD 文件。能否读取 CAD、生成可编辑 PPT、渲染与导出，需分别接入真实工具并验收。

## 原型结构

- 左侧：三类示意素材、品牌规则开关、正式素材接入说明。
- 中间：页任务、媒介选择、内容预览与设计理由。
- 右侧：预设对话、演示意见和预设局部修改。
- 底部：模型、上传、目标文件的未接入状态。

黑白灰显示，无远程字体、第三方图库、网络请求、跟踪脚本或浏览器持久化存储。自由输入用文本节点呈现，不作为 HTML 执行。提供键盘可用的控件、媒介标签方向键切换、对话框 Esc 关闭和减少动态支持。

## 检查状态

已通过 Node 的 JavaScript 语法检查，并静态确认没有 `src` / `href` 外部资源引用。本轮仅交付原型源码；没有启动服务，没有执行真实生成或导出。浏览器视觉与操作验收由主任务继续完成，不能把语法通过当成实际 UI 检查通过。
