# Panda 内容编排 v0.9 使用说明

这套 Skill 帮助设计师和其他汇报者，从上传资料与对话开始，弄清要让谁理解什么，再组织有依据的内容，按需要做成 PPT、杂志图片或汇报网页。案例学习覆盖从问题到方案的推演；视觉设计服务这条内容主线。

## 怎么用

把完整的 `panda-content-layout` 文件夹放入支持本地 Skill 的助手环境，保留其中 `SKILL.md`、`references`、`agents` 与 `examples` 的相对结构。在能读取该目录的助手中指定 [Skill 入口](../skills/panda-content-layout/SKILL.md) 后上传项目资料即可。单独上传一个入口文件会丢失按需参考，普通聊天环境也不保证能读取 ZIP 内文件。

可以这样开始：

> 使用 Panda 内容编排 Skill。这里是我的图片、图纸和已有方案，准备给业主汇报，希望他们理解这个设计为什么适合日常生活。先读资料，和我把表达方向理清楚，再做可编辑 PPT。另一个案例主要学习它的设计推演。已有确定的 Logo 和模板我会一并提供。

也可以简单说“这些图帮我做份汇报”。助手应先读已有内容，提出具体理解，只问会改变下一步的问题。无需先选模型、填长表或逐个调度制作工具。

本包是专业工作流，需要宿主提供文件读取、读图、制作和渲染工具。它不是独立软件安装包，也没有自动把新流程接到旧本地工作台。缺少某项工具时，助手说明具体影响并继续可完成部分。

## 实际会怎样推进

| 阶段 | 助手负责的工作 | 用户看到或可以修改的内容 |
| --- | --- | --- |
| 理解 | 区分本项目资产、设计案例、视觉参考、固定模板；核对内容与缺口 | 对任务的具体理解，以及少量关键问题 |
| 推演 | 从案例学习“问题、概念、转译动作、方案证据”，再回到当前需要 | 为什么选择这些内容，哪些是已定方案、解释或新建议 |
| 表达 | 将论点、图证、解释和承接关系组成内容脚本 | 要讲什么、先后顺序、重点与取舍 |
| 制作 | 选用实际适配的 Skill 与制作器，用真实内容做样张或整套 | 可查看的页面及实际文件；说明编辑范围 |
| 修改 | 判断反馈发生在哪一层，保留已对部分，更新相应内容与输出 | 新旧差异、当前版本与仍需确认之处 |

“用原案例学习思考”和“版面一模一样”分别处理。用户明确锁定模板时遵守锁定；只是提供学习案例时不自动照搬整页。年龄和性别不推导职业爱好，引用案例的业主故事也不变成新项目事实。

## 同一个内容如何变成三种成果

- PPT 面向讲解，主画面突出论点和图证，长解释可进讲稿；原生编辑与整页图片分别交代。
- 杂志图片需要每张可独立读，同时整组有节奏，保留高清输出和可修改源文件的实际范围。
- 汇报网页服务自助阅读，补足口头讲解上下文，并检查手机显示；整页图片查看器与响应式图文网站分开说明。

只制作用户需要的形式。增加第二种形式时复用事实和内容决定，并为媒介重新安排表达；不把横版 PPT 截图缩小就称手机网站。

## 怎样判断它确实有用

先看能否讲清用户的目的，概念是否落实到具体设计动作，证据是否支持主张；再看图文关系与文件是否可用。真正的审美判断依赖实际页面、参考和用户反馈，不能用导出成功或模型自评分替代。

新版加入对话、案例推演、共享内容和分层反馈规则，并保留已有 PPT/网页/图片制作分支。六个外部 Skill 的方法已核对并明确候选分工，但不宣称六套均已安装或完整运行。客户端自动理解、原生 CAD 与固定母版全面继承仍须各自的实际实现和验证。

## 开发入口

主入口：[panda-content-layout](../skills/panda-content-layout/SKILL.md)。工作底稿：[project-brief-template.md](../skills/panda-content-layout/references/project-brief-template.md)。案例方法：[case-reasoning.md](../skills/panda-content-layout/references/case-reasoning.md)。外部能力分工：[method-adapters.md](../skills/panda-content-layout/references/method-adapters.md)。

这一版由代理执行内容理解与设计判断；机器接入使用新增的 workflow API，不把整张工作底稿塞进旧 slides 字段。内容状态、证据关联、改稿影响和风格版本已有独立代码；它们不会从自然语言自动推理，也没有替旧排版器增加审美能力。准确的接口与阶段边界见[技能封装与接入](技能封装与接入_v0.9.md)。分享包携带通用规则和方法，不含私人方案图片、业主材料或本机路径。
