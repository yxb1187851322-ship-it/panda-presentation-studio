# 本地编排工作台

v0.10 已接入服务端模型 API，工作台提供分析资料、补充要求、生成页面、只修改当前页四个入口。2026-10-12 已通过界面完成 15 张图片预览与 6 份文档提取文本的分析、对话、规划、局部改稿和实际导出，生成 10 页 PPTX、离线 HTML 与 10 张 PNG。PPTX 含原生文字和独立图片对象；PowerPoint/WPS 人工编辑尚未验证，审美尚未获用户确认。模型名是供应商接口 ID，尚未独立核验官方上游身份。完整方法和输入范围见[模型与技能运行](模型与技能运行_v0.10.md)。

本轮默认 `gem-3.8-flash` 用于分析、对话与改稿，`tt-6.1-sol` 用于规划。实际分析约 222 秒、补充对话约 29 秒、规划约 262 秒、gem 局部改稿约 17 秒；TT 改稿曾在约 280 秒后超时，最终退款、实扣为零。4 次成功与 1 次失败合计实扣 0.4277 算力。这些是一次项目记录，不保证后续耗时或费用。

历史 v0.9 的“内容底稿”视图与 workflow 存储接口继续保留，记录当时助手写入的任务、阅读范围、论点与图证、设计判断及复核状态。上方新模型分析单独保存，不自动合并成同一份底稿；早期规则编排也不因此变成模型分析。

这是正式 Panda 接入前可独立运行的制作工作台。浏览器是本机界面，服务仅监听 `127.0.0.1`，资料保存在仓库忽略的 `data/`。关闭进程后项目仍保留，重新启动可继续编辑。

## 启动

需要 Node.js 22+、`@oai/artifact-tool`、`sharp`，文档解析还需要带 `pypdf` 的 Python。可以使用宿主已经提供的依赖目录，不复制捆绑运行时到代码库。

```text
node scripts/start-studio.mjs
```

默认入口 `http://127.0.0.1:4317`。可用 `PANDA_PORT` 调整端口。依赖配置在忽略的 `local/runtime.json`：`nodeModules` 指向已安装的 Node 包目录，`python` 指向 Python 可执行文件；环境变量 `PANDA_NODE_MODULES`、`PANDA_PYTHON` 优先。不存在这些私有路径的其他电脑需配置自己的环境，不能把开发机运行过等同于独立安装包完成。

模型密钥只在服务端读取：在项目根 `.env` 配置 `API_KEY`，已有文件保留原内容；也可通过 `PANDA_ENV_FILE` 或忽略的 `local/ai-config.json` 中 `envFile` 指定文件。配置示例见 [ai-config.example.json](../examples/ai-config.example.json)。真实 Key、凭据位置和私人资料不提交 GitHub，不写入 Skill 或浏览器。

界面区分“已配置”和“已记录成功调用”，已配置不能代表连通或质量合格。点击模型按钮会将本次任务所需的说明、历史上下文、压缩图像预览和已提取文本发送到配置的模型服务，并产生 API 调用费用。原件留在本机；已知实扣、未知费用和实际阅读范围分别显示。

## 实际使用

1. 新建项目，上传本项目图片和文档，填写这次汇报的用途。
2. 区分内容、Logo、平面图和排版参考。Logo 单独放置，参考素材不自动混入项目成品。
3. 点击“分析资料”，查看模型实际发送了哪些图片和文字、观察与事实的依据，以及待确认的问题。文件上传成功不等于已被模型阅读。
4. 在输入框填写补充要求并点击“补充要求”，逐轮校准表达目标与事实。模型不应凭模拟业主的年龄、性别推定爱好或职业。
5. 点击“生成页面”，把分析转成可由现有制作器执行的页面计划。在“设计编排”中查看、调整标题、正文、选图与叙事顺序。选中一页后可填写反馈，点击“只修改当前页”；其他页保留。
6. 到“制作交付”选择格式并制作。本轮模型新稿已实际导出含原生文字的 PPTX、离线 HTML 和页面 PNG；每个新项目仍须检查实际页面。照片与平面图是独立图片，其内部线条、家具与文字不会变成 CAD 或原生对象。
7. 修改后重新导出。旧版本保留在项目导出目录，页面入口只展示当前有效版本的产物。

“按规则快速编排”保留原有本地功能，不调用模型，也不表示执行了语义理解。当前模型页面使用封面、主视觉、图文并置、图片组、文字叙述、图纸说明六类版式；模型在这些能力内组织表达，不能生成任意版式或宣称一定具有高审美。

更新分析或讨论后，旧模型页面标记为待重新编排；改变项目说明、受众、素材用途或上传新资料后，先重新分析，再生成页面。工作台会阻止把未同步的旧页作为新版导出。局部改稿不能解除整套内容过期状态，相同内容的重复保存不会误触发。

## 本轮边界

CAD 接收不等于 CAD 解析。PDF 文本提取不等于 OCR 或完整页面理解。上传 PPTX 可用于读取内容，但当前不会继承整套固定母版或保留任意原对象。品牌 Logo 与颜色可使用，固定版面完整继承与正式 Panda 客户端接入仍是后续功能。

网页文件可离线打开；下载不等于公开发布。PNG 当前是页面输出，专门的竖版杂志构图仍需要进一步实现。当前没有 PDF 导出，不能把另一种独立输出说成 PPT 同源 PDF。

导出模块检查文字容量与文件结构，但自动检查不代表审美已通过。真实试制需要逐页看图，记录用户修改意见；未经过目标 PowerPoint 软件打开的文件不能宣称完成该软件兼容验收。

## 数据与恢复

项目通过修订号拒绝过期写入，导出时锁定当前项目。上传、重排或内容修改后，页面上的旧导出失效，磁盘上的历史产物不被删除。导出失败保留原件和已保存编排，可修改后再试。

模型调用使用项目快照，不持有项目写入锁。调用期间有其他修改时，迟到的模型结果只保存为本机候选，不覆盖新版。失败不会自动重复付费调用，输入框中的补充要求会保留，便于核对后重试。

当前是单机单使用者工具，不提供多租户认证。会话令牌、同源检查与项目路径校验用于保护本机服务，不应改成监听公网后直接作为线上服务使用。未来接入沿用 Panda 的身份、存储和模型网关。
