# 本地对话工作台

v0.11 将制作入口收成一个对话框。上传图片和文件，说明要向谁表达什么，之后直接对话和看结果。分析、编排、制作与单页改稿由后台按要求衔接，不再要求使用者逐项点击流程按钮。具体说法见[对话创作](对话创作_v0.11.md)。

这是正式 Panda 接入前可独立运行的本地工具。服务只监听 `127.0.0.1`，项目保存在仓库忽略的 `data/` 中，重启后可通过历史对话继续。新建对话不会删除旧项目。

## 启动

需要 Node.js 22+、`@oai/artifact-tool`、`sharp`；文档解析还需要带 `pypdf` 的 Python。可使用宿主已提供的依赖目录，不复制捆绑运行时到代码库。

```text
node scripts/start-studio.mjs
```

默认入口 `http://127.0.0.1:4317`。可用 `PANDA_PORT` 调整端口。依赖配置在忽略的 `local/runtime.json`：`nodeModules` 指向已安装的 Node 包目录，`python` 指向 Python 可执行文件；环境变量 `PANDA_NODE_MODULES`、`PANDA_PYTHON` 优先。其他电脑需配置自己的运行环境，开发机运行过不代表独立安装包已经完成。

模型密钥只在服务端读取。在项目根 `.env` 配置 `API_KEY`，保留已有内容；也可通过 `PANDA_ENV_FILE` 或忽略的 `local/ai-config.json` 中 `envFile` 指定文件。配置示例见 [ai-config.example.json](../examples/ai-config.example.json)。真实 Key 不提交 GitHub，不写入 Skill、浏览器或日志。

发送消息后，模型按需读取本次任务相关的说明、历史上下文、压缩图片预览和已提取文字，并产生 API 调用费用；一次制作可能包含多次调用。原件和项目记录保留在本机。仅重新导出已完成且有效的页面时，不重复调用模型。

## 使用

1. 点击“图片 / 文件”、拖入文件，或在输入框粘贴图片。附件先列在输入框上方，发送前可以移除。
2. 输入要求，例如：“这些是住宅方案资料，想给业主讲清楚一家人的生活与空间安排，请先和我讨论。”发送后，Panda 阅读可用资料并回复。
3. 继续补充用途、喜欢的参考和必须保留的内容。准备制作时说：“按这个方向开始制作 PPT。”结果卡直接提供文件与页面预览。
4. 需要改稿时指出页面和具体变化，例如：“第 3 页图片放大，正文只留两句。”当前局部改稿每次处理一页；整套逻辑改变时说：“按当前要求重新制作。”
5. 点击结果中的“下载 PPT”“打开网页”或“查看页面”。预览中可以切换页面并保存图片，随后继续在同一个输入框反馈。

Enter 发送，Shift+Enter 换行。只上传资料而不打字时，默认先讨论怎样组织内容。上传成功不等于全部内容已被理解，文件不可读或证据不足时仍需在对话中说明。

右上角“历史对话”可打开旧项目，“新对话”开始另一件事。早期项目的资料与导出保留；旧版按步骤操作的 API 继续供代码使用，主界面只提供对话入口。

## 中断与恢复

任务进行中会显示“阅读资料”“组织内容”或“生成文件”等简短状态。浏览器暂时没有收到响应时，使用“查看处理结果”查询原任务；查询不会再次提交付费请求。

导出失败会保留已生成的页面，可以说“重新导出”。模型失败不自动重试。任务处理中可以先写下一句，回复返回时会保留新输入。同一个页面内切换历史对话会保留各自草稿与未上传附件；已发送附件保存在项目中，尚未上传的附件不能保证跨刷新保留，离开页面时会提醒。

同一项目通过修订号防止旧写入覆盖新内容。模型调用期间若其他地方已改动项目，迟到结果保留为本机候选，不覆盖新版。当前界面只显示与最新内容一致的导出，磁盘上的历史文件不被删除。

## 目前能交付什么

PPTX 使用原生文字和独立图片对象；照片里的家具、图纸线条和图片文字不会转成可编辑形状。网页是可离线打开的 HTML，PNG 是当前页面的输出。下载不等于公开发布。

当前制作器支持六类有限版式，模型在这些能力中选择，不能自动实现任意版面。对话上传统一保存为内容资料，尚未实现从聊天自动设置参考角色、绑定 Logo 或锁定模板。CAD 接收不等于 CAD 解析，PDF 文本提取不等于扫描 OCR 或完整页面理解；上传 PPTX 暂不能完整继承任意固定母版。独立竖版杂志构图、PDF 导出和正式 Panda 客户端接入仍待实现。

自动检查文字容量和文件结构不能保证审美。每轮仍需实际看页面，记录具体修改；PowerPoint/WPS 中打开与人工编辑尚未完成验收。

## 开发与验证

```text
npm test
node scripts/verify-resources.mjs
```

v0.11 全套 187 项自动化测试通过，无跳过。浏览器隔离测试使用模拟模型，实际完成图片与文档上传、对话制作、单页改稿及 PPTX / HTML / PNG 导出，检查了处理中刷新、草稿与附件保留、预览、历史和窄屏布局。新对话入口的付费模型意图识别尚未实测，具体范围见[对话创作验证](对话创作_v0.11.md#验证范围)。

v0.10 的历史真实调用与 171 项测试记录见[模型与技能运行](模型与技能运行_v0.10.md)。两轮证据分开记录；测试通过不能代替目标软件兼容性、用户审美认可或正式产品验收。

当前是单机单使用者工具，没有多租户认证。保留同源、会话令牌与路径校验，不将本机服务直接暴露到公网；未来上线沿用 Panda 的身份、存储和模型网关。
