# Panda 内容制作 v0.8

这版把内容理解、指定参考和实际制作合到代理工作流。用户上传与对话，代理选择当前环境能执行的工具。入口为 [panda-content-layout](../skills/panda-content-layout/SKILL.md)。它面向可读取 Skill 的代理，不是双击即可运行的 Panda 安装包。

## 使用方式

将整个目录交给代理，并给出本轮资料，例如：

> 使用 skills/panda-content-layout/SKILL.md，读取这些项目图片和文档，沿用我给的原版。先制作一张包含真实内容的样页，输出 PPT 和预览。保留原图与 Logo，需要核对的事实标出来。

已有素材、参考和对话决定不重复索取。要可编辑标题、完整可编辑对象或手机网页时，直接说实际用途；代理分别选择制作路线和检查对象，不能只凭扩展名承诺能力。

## 新增的实际内容

- 内容单元连接来源、素材、状态及必要标签。
- 参考绑定包含实际画面观察、保留关系和逐项对照。
- 原生模板、整页保真、参考视觉稿与可编辑重建分别选择。
- 图纸、尺寸、材料标签和 Logo 采用原资产，禁止默认重画。
- 样张制作、视觉复核和用户认可分别记录。
- 已完成的样页可用独立脚本封装为离线查看页及附件。

```text
node scripts/production-manifest.mjs check manifest.json
node scripts/production-manifest.mjs bundle manifest.json --out delivery-v1
```

[清单格式和最小例子](../scripts/production-manifest.md)。脚本只检查记录、文件及引用，并打包现有结果；内容理解、PPT 制作及看图由代理实际执行。查看页是等比图片浏览，不冒称响应式图文网站。

## 本地试验覆盖

第一种路线用内置图像工具，沿指定双图参考制作一张产品流程说明页，再组装图片式 PPT。第二种路线保留原 PDF 页面的署名、材料图和标签，只将概念题注重建为可编辑中文。原资料与样页均留在本地，不随代码分发。

已检查逐页渲染、PPT 文件结构、内置库回读、原资产嵌入字节以及中文文本对象。用户尚未认可样页，原生 PowerPoint 未实测。清单工具的测试不证明审美合格。

## 与产品的关系

正式 Panda 客户端接入、多模态模型网关、原生 CAD 解析和自动固定母版继承仍需后续实现。这版已经能在代理环境执行具体制作步骤，但旧工作台的规则初排不会自动变成这套流程。

工作流借鉴 [Codex PPT Skill](https://github.com/ningzimu/codex-ppt-skill/tree/85d4e629275e6c5793a33801d29b364383ea4c1e) 的内容大纲、具体参考、样张和逐页视觉生成方法，并结合用户提供的杂志与网页 Skill。Panda 按既有授权继续制作，未继承逐阶段重复提问；使用当前可用工具，不写死模型型号。完整上游未全局安装，可编辑转换项目仍是待验证候选。
