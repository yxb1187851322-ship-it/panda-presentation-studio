# 本地资源使用

完整资料继续保存于原方案工作区，包括 13 份原稿、4 个用户指定来源文件、解压包、预览、历史对话与整理记录。仓库提交方法、Skill 和文件索引，原件不因建库而移动或改写。

本机绑定文件为 `local/library.local.json`，内容为 `{"root":"你的完整资料库根目录"}`，已被 Git 忽略。其他电脑可按此创建文件，或使用环境变量 `PANDA_LIBRARY_ROOT` 临时指定根目录。不要将 API 密钥写入该文件。

```text
node scripts/local-library.mjs status
node scripts/local-library.mjs list
node scripts/local-library.mjs resolve R00-original
node scripts/local-library.mjs resolve R00-original --verify
node scripts/local-library.mjs resolve R09-P008-preview
```

`status` 只核对已登记资料的存在与字节数，不声称重新完成全部哈希或内容阅读。`resolve` 返回指定文件的绝对路径和登记状态；`--verify` 额外计算该文件 SHA-256。脚本不打开程序、不执行原包脚本、不上传文件。

实际文件清单保存为忽略的 `local/assets.local.json`，格式见 `resources/sources/local-assets.schema.json`。文件名、路径、哈希与私人历史索引都只保留本地。一个资源可有多个逻辑别名引用相同物理文件；需要把原稿交给解析器时，宿主据此定位，再依当前项目使用范围读取。其他电脑使用自己的清单，公开仓库不包含开发者的实际文件清单。

已有 31 张设计卡：20 张原稿代表页覆盖 13 份，另 11 张去重杂志参考。原稿总计 1074 页并未全文逐页看完。没有本机原稿的协作者可阅读方法卡与界面原型，但不应声称看到原始画面。

资料读取、模型分析和向外部服务传输是不同动作。本地绑定只提供文件定位，不自动授权任何服务取得全部资料。
