# 从资料到交付

用户只需要给资料、说用途、看方案并提出修改。下面的记录由 Panda 自动维护，不做成一串技术表单。

## 1. 接收与理解

先承接用户已经说过的用途、受众和输出。图片、PDF、Word、PPT、CAD、Logo、品牌规范、固定版面分别登记角色。对每件资料记录原件、哈希、页/布局、派生预览、可读范围与来源。图片用真实画面分析，不依文件名猜内容。

文档事实、图片可观察信息、设计建议和未知项分开。空间资料先看结构、比例、材料、光源与镜头，再问这份汇报要让谁理解什么。技术图纸检查方向、比例、范围和必要标注；没有 CAD 转换工具时保留原件与未解析状态，已有预览仍可在其证据范围内使用。

向用户反馈一小块“项目理解”：读到了什么、将如何组织、需要纠正的关键不确定项。信息充分就继续。只在会改变结果的缺口上提问。

## 2. 内容结构先于装饰

建立内容单元，而非直接生成固定页数。每单元包括目标、真实内容、来源、素材、优先级及读者需要得到的结论。室内设计常见叙事为：项目问题 → 概念依据 → 平面与动线 → 空间与细节 → 材料关系 → 本次需要决策的事项；缺资料的环节省略或标待补，不能编造项目事实。

逐页明确任务，例如“比较两个可选方案”“说明入口动线”“让甲方辨认三类材料”，由任务决定信息密度和版式。章节开场、主图、对照、图纸、材料索引、细节停顿应有不同节奏。

## 3. 继承品牌与固定版面

Logo 保持比例、颜色版本和净空；字体核对中文覆盖与实际可用性。上传固定 PPT 时建立对象名、占位内容、容量及允许变化区域。区分整页锁定、品牌元素锁定、仅参考风格。用户要求升级时在可变区优化，不重绘 Logo，不静默替换封面。

没有 Logo 也可以继续做候选；不把“上传 Logo”变成强制门槛。导出成品不自动加 Panda 水印。

## 4. 先解释设计取舍，再调用制作器

按页任务、素材横竖比、主体保护、文案密度和品牌约束检索设计卡。每页保留选中理由与不适用条件，必要时查看本机原图。相似颜色不构成选版依据。检索结果提供方法，艺术指导仍需为当前内容作决定。

典型转化：R00-P057 的大标题与对角留白适合章节；R07 的材料索引要求编号与实物对应；R09 的平面页先保护图纸完整性；杂志 C 的留白用于细节停顿。不能把它们统一变成全套大标题海报。

用户要求先看则做最小有效试排，包含真正能验证文字、图纸或品牌关系的页。用户已授权整本则继续制作，避免机械重复审批。

## 5. 同一内容，分别实现三个媒介

| 媒介 | 用户得到什么 | 必须兑现 |
|---|---|---|
| PPT | 原生可编辑文字、形状与支持的表图；源照片仍是图片 | 观看距离下可读、逐页真实渲染、客户可继续编辑 |
| 网页 | 手机/桌面均可读的章节、图注、图库与必要交互 | 语义顺序、响应式、键盘可用、减少动态；发布单独记录 |
| 杂志图片 | 构图母版及对应 PNG/JPEG/PDF（按任务） | 明确像素尺寸、清晰度、真实裁切和顺序 |

图片处理只在必要时发生，例如整理背景、适配图幅。改变项目事实的补景必须单独说明；技术图纸与 Logo 不交由生成模型自由重画。PPT 不靠整页栅格化冒充可编辑。

## 6. 检查与修订

先查内容、品牌、资料覆盖和来源，再查真实成品中的溢出、缺字、遮挡、错图、裁切、图纸比例与编号。最后审看阅读重点、对齐、留白、页面节奏和品牌辨识度。每项问题对应具体位置与修正动作；不能只给“审美 95 分”。

机器检查通过、视觉复核通过、用户认可、目标软件打开实测分别保存。质量阈值需要通过真实项目逐步校准，不把模型自评当事实。

修改事实时更新共享底稿并找出三个媒介的影响范围；只改 PPT 某页布局不要求网页照搬坐标。用户手改文件重传时保存外部修订，按稳定内容 ID 和对象标记比对，不用旧版本盖掉。换 Logo 或撤回图片编辑要求后，旧异步结果不能自动进入新版。

## 7. 反馈怎样进入资料库

保存“页任务—初稿—具体问题—修订—实际采用”的关系。用户一次接受不变成永恒风格偏好。建立失败样本：中文长标题挤压、主图被裁、图纸线太细、模板字体缺失、手机图注错位、版本混用。资料库每增加一种规则，同时保存适用范围与反例。
