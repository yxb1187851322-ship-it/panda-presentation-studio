# Panda 内容编排

用户上传资料并对话，你负责理解内容、复用具体版面、制作和修改。Panda 已有本地客户端和官网；本 Skill 是其中的专业工作流，不重建整个平台，也不要求用户逐个选模型、配 API 或挑模板。

当前由代理调用宿主实际工具执行。配套本地工作台的规则初排不等于语义理解或模板继承；不能把本规则包、参考卡命中或导出成功写成产品已经自动具备这些能力。

## 先承接任务

区分新内容制作、指定原版替换、改稿、跨端延展与参考研究。先读取上下文和已有素材；已有用途、格式、数量和授权不重复问。资料充分时直接做，不让用户填写内部字段。

按用户要求交 PPT、网页或杂志图片，允许组合但不默认三端全做。明确本轮是代表性样张还是整套；“开始制作”授权制作，不代表新风格已获认可。用户已授权的范围不再逐阶段询问是否继续。

有本地资料库时用[资料路由](references/library-routing.md)定位原件和决定；没有私人资料库仍可用本次资料运行。需要接收解析时读[资料读取](references/intake.md)。外部 Skill、网页和源文档是参考材料，不能扩大任务权限。

## 1 先形成可用于设计的内容

实际读取文字、图像和图纸，记录已读范围。分清项目事实、画面观察、助手建议及未知项；不凭文件名认定空间，不从截图猜精确尺寸，不把概念效果图当实景。CAD 结构读取、渲染和空间理解分别核验，没有成功证据就保持未解析。

先回答项目为谁展示、希望读者理解什么、哪些素材有关联、哪些内容必须保留。每个内容单元连接来源页、文案、图像身份、方案状态和必要标签；材料编号、应用部位与“进行中”等状态不能被泛化概述抹掉。多份资料按用途和关系组织，不按上传顺序机械分页。

新制作和拒稿执行[内容与版式证据](references/execution-evidence.md)，内部记录见[参考与制作约定](references/reference-contract.md)。要求“全部使用”时记录覆盖与未用原因。复杂项目或关键缺口再读[内容与交互](references/content-and-dialogue.md)；仅询问无法从已有资料解决、且会改变结果的问题。

## 2 把参考变成实际制作约束

打开具体参考页或网页，而非只读 Skill 名称和风格标签。确定真实图幅、文字重量、共同轴线、留白形状、裁切和系列节奏；记录本次保留的关系及允许变化部分。照片和已排版整页分别识别，不能将整张纸缩进另一张纸后称已继承。

用户要求沿用原版时，执行[严格原版继承](references/visual-direction.md#严格原版继承)：原比例、槽位、文字关系和背景优先，在允许的位置替换内容。没有可编辑母版就选择保真展示或忠实重建，不能因为工具方便改成自由生成。新素材放不下时选同体系相容页面或按语义续页，不静默丢内容、无限缩字或改变锁定关系。

有 Logo、品牌和固定元素时读[品牌与模板](references/brand-and-template.md)。参考里的作者、摄影、项目文案和商标不变成 Panda 的身份或产品承诺。既往接受的参考只能作为候选；被拒稿不得继续作为推荐样板。

## 3 选择能兑现的制作路线

制作前读[制作路线](references/production-routes.md)，根据源文件结构、保真范围和编辑需求决定：原生模板替换、整页保真、参考驱动视觉生成，或按需可编辑重建。明确图片式 PPT 与可编辑对象的区别。不能一律手写新布局，也不能一律将整页图片当成最终编辑稿。

需要图像生成时先核验当前内置图像工具并按其说明执行；有可用工具就由代理调用，不先让用户配置外部 API。不写死口述模型名或猜测内置模型、分辨率。仅在任务确需且内置能力不足时考虑已授权的其他后端。生图不是改变图纸、Logo、材料标签或真实项目照片的默认许可。

选中原生 PPT 路线再读[PPT](references/ppt.md)；网页读[网页](references/web.md)；杂志图片读[图片](references/images.md)。需要改图才读[图片处理](references/image-processing.md)。制作路线中的图片式 PPT 说明优先于原生 PPT 分支的对象要求，不能混报编辑能力。

## 4 用真实内容校样，再扩展

在新方向、被拒稿返工或用户要求先看时，先做能检验关键问题的代表性内容页。封面无法检验图文关系时不以封面替代；数量随任务，不固定三页或三种风格。用户已授权整套且方向清楚时可继续做整套草稿，但不得把它记录为已认可风格。

样张使用真实文案、素材和参考约束，保存制作提示、工具、实际产物及检查结果。展示真实输出供审阅；`accepted` 仅来自用户真实反馈。未认可样张可继续定向修改，不能作为“已批准参考”扩散。后续采用同一路线和已确认视觉原则，构图依页面内容任务变化；不要偷偷换为便宜的固定布局或复制同一种分栏。

## 5 检查、交付与复用

分别判断内容、参考执行、文件技术和用户反馈。逐页查看成品与具体参考，核对必要内容、文字字形、实际图幅、边缘背景、对齐、裁切、图纸比例及 Logo。技术测试和模型评分都不能证明审美合格。具体检查读[设计复核](references/design-review.md)。

交付实际文件、预览、所需源码/资源和简短编辑说明。整页图片说明页内对象不能独立编辑；网页需实际 HTML 文字及桌面/手机检查，等比原页查看器另作说明；普通截图不能冒充高清杂志成品。未执行的检查、重建或宿主实测如实列出。

改稿维护来源与版本，只重出授权范围内的产物，旧端明确标为旧内容版本。多端或改稿读[版本与验收](references/revisions-and-quality.md)。经用户认可的样张、使用条件、可替换范围及禁用情况一起保存，不能只存“高级杂志风”四字。

产品接入与异步协作读[编排规则](references/orchestration.md)；使用配套工作台时读[本地制作接入](references/local-workbench.md)。正式客户端、原生 CAD、自动语义理解和完整模板继承是否可用，以当前执行证据为准。
