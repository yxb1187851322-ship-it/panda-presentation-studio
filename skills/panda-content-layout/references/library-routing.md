# 资料库路由

本Skill可以只用当前用户提供的资料运行。开发资料库是可选输入，其他人的案例不能直接作为当前项目素材。

## 使用设计库

宿主连接本代码仓库时，可从 `resources/design-library/index.json` 按页任务、素材结构、品牌和媒介选择设计卡，再读取对应的方法与限制。卡片使用匿名来源ID与页码，不包含私人原件路径或指纹。

本机可通过忽略的 `local/library.local.json` 指定资料根目录，通过 `local/assets.local.json` 将逻辑ID映射到实际文件。格式见 `resources/sources/local-assets.schema.json`；运行 `scripts/local-library.mjs resolve <id>` 定位具体原件。路径与哈希留在本机，不能为了便于检索而自动公开。

先限制到本项目获准访问的资料范围，再做内容匹配。研究卡的观察记录不等于当前操作者已看过原图；需要判断具体画面时实际读取。文件定位不等于已上传模型，也不扩大服务的资料访问权限。

当前研究范围为20张原稿代表页与11张杂志图例，不代表全部1074页原稿已读完。每次新增记录保存观察、推导、适用、反例与未读范围，按本次任务读取足够证据，不一次装入全部原件。

## 没有本机绑定时

直接用本次素材、用户指定参考和实际可用工具推进。缺少具体原图且确实影响判断时说明边界；没有私人开发库不构成通用Skill不可用的理由。

如果用户需要接自己的资料库，由宿主提供同等作用的路径映射和来源ID，不要求相同盘符或沿用开发者的文件夹名称。

## 携带范围

通用规则包携带专业方法、分支要求与虚构示例。私人原稿、客户资料、字体、原图与历史对话留在各自授权工作区。学习设计关系、读取素材与公开分发是不同范围。
