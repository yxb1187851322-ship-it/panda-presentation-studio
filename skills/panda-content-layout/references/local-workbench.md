# 本地制作接入

配套仓库存在 `scripts/start-studio.mjs` 与 `studio/` 时，可使用本地工作台承接已授权制作。完整运行依赖和接口在仓库 `docs/本地工作台.md`；独立复制本 Skill 时这些文件可能不存在，应检查实际环境。

工作台负责原件保存、受限文字提取、模型分析、页面编排和 PPTX/HTML/PNG 导出。v0.11 用户入口为一个对话框，文件与预览直接返回对话，不再提供分步分析、规划和导出面板。部署时由系统检查实际配置，不能由版本名称推定 API 已通。模型运行、输入覆盖、实际制作和用户认可分别保留证据；当前使用与验收见仓库 `docs/对话创作_v0.11.md`，历史真实模型记录见 `docs/模型与技能运行_v0.10.md`。

## 开始一轮制作

1. 上传资料并说明用途、给谁看、希望讲明白什么；沿用项目已有要求，避免让用户重复填写。
2. 系统按当前状态分析资料或继续对话，传入可读文本、实际图像和按需加载的方法；检查本轮读取了哪些资料，未读部分继续标明。不要让用户先寻找模型或流程按钮。
3. 用对话回应理解和关键问题，补充会改变表达方向的信息。项目事实、画面观察与提出的建议保持区分。
4. 用户要求开始制作时，后台形成页面计划并生成真实文件和预览，结果显示在对话中。先检查能验证核心问题的内页；模板锁定依赖实际可用能力，不能只凭口头承诺。
5. 用户说明具体页码和修改要求后，后台修改该页、保留其余页并重新导出。用户改变整套方向时重新编排；缺少明确修改页码时先澄清。

旧规则编排接口仍可依据可读文本、尺寸和角色初排，但不提供视觉语义理解，也不是新界面的用户入口。模型分析不能代替文件制作；只有渲染器完成导出后，才提供本轮文件。

新对话上传暂将附件统一保存为内容角色，不会自动根据聊天设置参考资产角色、`brand.logoAssetId` 或模板锁定。可理解用户说明，但应明确绑定尚未执行，不宣称参考已隔离或 Logo 已自动应用；这些自动绑定仍需后续实现。

先接收原件并检查 `status / warnings / readScope`。PDF/PPTX 的原生文本可读不代表图像已读；图纸 PDF 只有文本时，不把零碎标注当作完整图纸页面。需要可用预览才能做图纸试排。

用项目 `revision` 保存修改，409 表示已有新修改或任务正在执行，读取当前状态后再处理，不能用旧页无条件覆盖。导出后真实 PNG 对应本轮文件，用其检查中文断行、图片比例、图纸与 Logo；来源、自动检查、视觉检查、用户认可分别保留。

文字、图注与页码是原生可编辑对象。照片及图纸内的对象仍是位图。当前 PNG 共用横向页面布局，专门的竖版杂志构图需另外设计。当前不会保真继承整套固定母版，不可把上传旧 PPT 成功当作品牌模板继承完成。

模型只为已接通的制作能力制定计划。不要让模型承诺尚无工具执行的 OCR、原生 CAD、图片生成、完整母版继承或任意网页动效。没有实际查看渲染时，记录为待视觉检查；技术导出通过不自动使某种版面进入 Panda 默认风格库。

真实素材与导出进入本机项目目录，不随代码提交。对外展示用经过审查的自有或获授权案例；内部参考重排保留原作者出处，不伪称新客户成果。
