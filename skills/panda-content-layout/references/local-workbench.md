# 本地制作接入

配套仓库存在 `scripts/start-studio.mjs` 与 `studio/` 时，可使用本地工作台承接已授权制作。完整运行依赖和接口在仓库 `docs/本地工作台.md`；独立复制本 Skill 时这些文件可能不存在，应检查实际环境。

工作台负责原件保存、受限文字提取、规则初稿、逐页编辑、PPTX/HTML/PNG 导出。规则编排只依据文件可读文本、尺寸、角色和研究卡标签，不声称完成视觉语义或语言模型分析。助手需要实际看图并调整每页内容、图文关系与图注。

先接收原件并检查 `status / warnings / readScope`。PDF/PPTX 的原生文本可读不代表图像已读；图纸 PDF 只有文本时，不把零碎标注当作完整图纸页面。需要可用预览才能做图纸试排。

用项目 `revision` 保存修改，409 表示已有新修改或任务正在执行，读取当前状态后再处理，不能用旧页无条件覆盖。导出后真实 PNG 对应本轮文件，用其检查中文断行、图片比例、图纸与 Logo；来源、自动检查、视觉检查、用户认可分别保留。

文字、图注与页码是原生可编辑对象。照片及图纸内的对象仍是位图。当前 PNG 共用横向页面布局，专门的竖版杂志构图需另外设计。当前不会保真继承整套固定母版，不可把上传旧 PPT 成功当作品牌模板继承完成。

真实素材与导出进入本机项目目录，不随代码提交。对外展示用经过审查的自有或获授权案例；内部参考重排保留原作者出处，不伪称新客户成果。
