# 网页分支

以共享内容单元组成连续阅读章节，使用真实HTML文字与独立图片。用户要求网页时，默认成品展示，不替换为上传后台、自助编辑器或PPT截图翻页。

简单专题可用HTML/CSS/JS，已有工程沿用适合的栈。电脑与手机分别检查文字断行、图窗、顺序和裁切，不只是等比缩小。图片带固有尺寸并合理分配加载优先级；字体与素材的来源和使用范围可追溯。

图片专题优先由真实图片比例决定章节高度。大图与紧凑图注共享边缘，竖图可配窄说明栏；只有明确的叙事作用才使用固定屏高。保留完整空间的图片使用自然宽高，不能用统一横向 `aspect-ratio` 与 `contain` 制造大量内部留白。手机重新组织图片和说明的先后与间距。整页参考截图作为参考展示时保留原页，作为内容生产时应先识别独立素材边界。

需要动态时再增加动效。动效服务阅读，检查进入、中段、离开和反向滚动；图窗不得压住仍需阅读的文字。支持减少动态，关闭动画后所有内容可读且无冗长空白。查看器、按钮、导航支持键盘、Esc、标签和焦点返回。

小型纯静态专题可以自包含HTML；多图、视频或复杂工程采用完整目录。打包工具不支持模块、响应式资源或视频时换适合的方式，不删需求来迎合旧脚本。离线能力需断网或阻断外网后实测，不能把内联成功等同于离线完整。

检查桌面、手机首屏/中段/末段、图片解码、横向溢出、浏览器异常、字体字形、按钮和链接、动效中间状态。基础自动检查不能替代整页和交互检查。

文件交付按本次约定执行。用户仅要本地文件或可分享附件时，不部署；用户请求公网链接时，核验托管能力、可见范围和实际授权后执行。未部署不把file路径或localhost说成他人可访问网址。

交付主HTML或工程目录、编辑源码、必要资产和简短打开说明。用户另要正式封面时走图片分支重新渲染，网页屏幕截图只作预览。
