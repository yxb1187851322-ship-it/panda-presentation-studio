# 从案例提炼的四种工作方法

以下是对已读原稿的研究归纳，供方法迁移，不是作者原话或完整设计过程复原。来源仅用匿名案例 ID 与物理页码；私人原图、名称、路径及完整研究留在本地资料库。没有原件时可使用这里的通用方法，但不能宣称自己已看过原页。

## 1 把模糊偏好拆成具体变量

来源：R00 P57–65。原稿先给出“更多方向”与结合两张参考特征的场景，再展示相同基准的不同变化。

应用：用户说“更有品位”“更温暖”时，结合真图指出可调整的是材料触感、空间开合、家具关系、信息密度或文字重量。比较时保持必要基准，说明变化的对象与保留的条件。只有用户授权调整设计，才改变空间；仅调整汇报时，变量应落在内容和表达。

失效条件：不同空间、不同机位的图片不能声称严格单变量对照。不能把原稿标示的视觉融合比例、速度和效果当成 Panda 经实测能力。

## 2 文化意象要经过转译才能成为设计

来源：CASE-RES-01 P11–15、20–26。原稿从一个文化载体，拆出虚实、遮蔽等关系，再进入构件、光影、比例层级、材质及具体活动场景。

应用：建立“意象 → 操作词 → 可见空间动作 → 当前项目证据”。例如一处界面怎样遮蔽或透光、构件如何重复、材料放在哪个面，而不是只写“东方雅韵”。PPT 可先解释一条最关键的转译，再用完整空间图与细节验证；不必复制原案例的文化题材或所有章节。

失效条件：效果图能支持构图和可见材料外观，不能独自证明历史工艺、材料规格、工程性能或当前客户喜好。

## 3 同一个场景分层解释，减少读者猜测

来源：R09 P16–21、33–35、55–65。原稿在相关空间中分别表达高度、动线、视线、材料位置及开关状态；部分页面明确写出状态变化产生的环境差别。

应用：先用总图说明在哪里，再给阅读这一问题所需的一层信息，最后用状态或细节验证。已有图纸保留原几何；分析标记与原图分层。只有一张效果图时，不冒充已经完成动线与工程校核。

失效条件：不能把“看起来安静”写成隔声达标，也不能以图中有电梯就宣称无障碍完成。多个使用需求可并存，不强行归结为一个文化主题。

## 4 让反馈成为可以局部执行的动作

来源：R00 P84–86；另结合 Panda 实际拒稿经验归纳。原稿以对象、位置与前后图说明修改。

应用：记录用户改的是目标、论点、证据、版面还是媒介；定位受影响内容和产物，再定向修改。喜欢 A 的某个特点不等于认可 A 全部；“再清楚一点”先检查缺解释还是读不清。事实变化应追踪全部引用，局部字体调整不自动重做设计方案。

失效条件：没有用户真实反馈，样张不能标已认可。多次技术成功也不能冲销排版被拒。

## 组合起来怎样使用

先从对话选出本次最需要解决的问题，再用一两条方法形成内容脚本。设计推演是上游；视觉模板、渲染器和图片处理是表达它的工具。既有方案做有证据的解读，方案共创做标明身份的建议，不需要为证明使用了方法而虚构一段设计历史。
