# 视觉方向与参考学习

先看本次指定参考及真实素材，再决定文字角色、图像主次和阅读顺序。已有稿件修改时承接已确认体系，不自动另选风格。

## 严格原版继承

用户指定沿用原版时，原版是需要复现的基准，不是可自由发挥的灵感。先定位并查看实际原页，记录其画幅比例、图片槽位及裁切、字体字号、字重、行距、留白、文字位置和对齐关系。原生模板能读取的值直接继承；只能观察的项目标明证据范围，不把猜测写成原版参数。

先复用原模板，再在原槽位替换用户允许更换的内容。保持原有标题和文案，除非用户明确要求改写；不得另起标题、放大主图、缩小文字、重设背景或改变版心来“提升审美”。新内容与槽位不相容时说明具体差异，继续完成兼容部分，不偷偷裁掉必要内容或将整个页面换成新设计。

原稿PDF或图片没有可编辑模板时，明确两种产物的边界：整页保真展示保留原构图，可作为阅读或对照基准，但页内对象不可独立编辑；可编辑复刻则重建文字、图片和位置，逐项检查与原版的差异。将整页图片放入PPT只得到整页图像对象，不能称为可编辑母版。字体缺失、提取失败或对象无法复原时记录限制，不自动切回自由排版。

此分支下不提取图纸另起版面，不裁掉原页留白，也不把内容重新分配到侧注或底注。只有用户明确允许调整某项时，才改变该项并保留其余锁定关系。跨端输出优先展示原页及适合目标屏幕的阅读方式；重新设计网页或杂志版面需要符合本次明确授权。

以下参考学习与新构图建议只适用于用户允许重新设计的部分。

参考卡记录：来源文件与页码、用途、字形特征与证据等级、字级关系、图幅、对齐轴、留白形状、背景、序列节奏、可复用关系和新内容需要调整之处。仅凭缩略图不认定精确字体或尺寸。

先通过[品牌规则](brand-and-template.md)明确固定模板的锁定项，再检索相容的设计逻辑。新资料库按页任务和素材结构检索，具体路径见[资料路由](library-routing.md)。观察和应用推导分开；参考有缺字或可读性问题时保留为反例，不连同缺陷复制。

原生信息、视觉观察、候选替代、未知分别标记。字体可用性和中文字形需在制作环境验证；没有目标字体就如实提出替代，不静默回退或横向拉伸文字。

视觉规格包含文字角色、字体及替代状态、层级、版心、背景使用、图注、主副图关系、裁切保护与适用范围。对用户用一句具体的编排建议表达，例如“让空间轴线完整展现，标题靠左对齐正文，细节页降低图幅形成停顿”。

图片保护区与文字区域同步规划。不同媒介独立调整阅读密度：PPT服务逐页讲解或审阅；网页服务连续浏览和手机屏；杂志图片需要固定画幅内成立。不要把网页卡片规则、图片2160px或PPT固定坐标当成共享设计规则。

系列可以有满版、留白、远景和细节变化，但不固定四章，不平均九宫格，不每页复制同样重的大标题。黑白、暖灰与彩色都可选，空间类型不决定模板颜色。

用户当前选择优先于任何包内历史审美记录。第三方参考可用于观察方法，不能移除署名当作用户作品，也不能默认塞入可公开发布的素材包。

最终以实际渲染做[设计复核](design-review.md)，不能以模型声称“高审美”替代检查。

## 从参考落实到构图

用户允许重新构图并选择参考后，在制作说明中写出三件事：保留的图文关系、因本次素材而改变的关系、渲染后怎样对照。严格原版继承时改为记录锁定项与获准替换项，不能套用本节建议进行二次设计。不能只写“参考极简风”，然后回到默认左右两栏。

- 先分清照片、材料拼板、绘图本体与已排版整页。整页截图里的白边、原页脚和标题不属于图纸几何；需要独立图纸时从原文件提取绘图区，核对完整边界并单独保留出处，不把整张纸再次缩进另一张纸。
- 图像的实际可见范围才是图幅。`contain` 框很宽，不代表内部竖图很大。先按原比例计算真实宽高，再安排文字与边距；不要把竖向材料、横幅摄影和细长平面统一塞进横框。
- 文字重量由内容任务决定。作品展示常用大图与窄题注；技术解释需要正文时再留说明区。文件名、工作状态、素材编号与制作提醒不能自动升级为主标题或大段正文。
- 背景与素材边缘一起判断。白底图纸在白色纸面上可以连续，摄影可使用另行设计的底色或满版。不因为某张图纸需要白底就禁止整套使用其他色彩，也不默认奶油色适合任何图片。
- 对齐检查真实图片边缘，而非外部容器。图片、标题、图注至少要有可解释的共用轴线；大留白要服务主体或阅读停顿，不能来自固定章节高度和空网格行。
- 图片占比只在相近任务、相近画幅内比较。完整竖图在横版PPT中面积较小可能合理，只要高度、文字重量与构图主次成立；不得为了达到统一百分比强行裁掉图纸或空间。

本地规则规划器只能读取尺寸和显式角色；没有视觉模型时，以上主体、边界与语义判断由实际看图完成，不能把规则命中当作理解了照片。
