# 视觉方向与参考学习

先看本次指定参考及真实素材，再决定文字角色、图像主次和阅读顺序。已有稿件修改时承接已确认体系，不自动另选风格。

参考卡记录：来源文件与页码、用途、字形特征与证据等级、字级关系、图幅、对齐轴、留白形状、背景、序列节奏、可复用关系和新内容需要调整之处。仅凭缩略图不认定精确字体或尺寸。

先通过[品牌规则](brand-and-template.md)明确固定模板的锁定项，再检索相容的设计逻辑。新资料库按页任务和素材结构检索，具体路径见[资料路由](library-routing.md)。观察和应用推导分开；参考有缺字或可读性问题时保留为反例，不连同缺陷复制。

原生信息、视觉观察、候选替代、未知分别标记。字体可用性和中文字形需在制作环境验证；没有目标字体就如实提出替代，不静默回退或横向拉伸文字。

视觉规格包含文字角色、字体及替代状态、层级、版心、背景使用、图注、主副图关系、裁切保护与适用范围。对用户用一句具体的编排建议表达，例如“让空间轴线完整展现，标题靠左对齐正文，细节页降低图幅形成停顿”。

图片保护区与文字区域同步规划。不同媒介独立调整阅读密度：PPT服务逐页讲解或审阅；网页服务连续浏览和手机屏；杂志图片需要固定画幅内成立。不要把网页卡片规则、图片2160px或PPT固定坐标当成共享设计规则。

系列可以有满版、留白、远景和细节变化，但不固定四章，不平均九宫格，不每页复制同样重的大标题。黑白、暖灰与彩色都可选，空间类型不决定模板颜色。

用户当前选择优先于任何包内历史审美记录。第三方参考可用于观察方法，不能移除署名当作用户作品，也不能默认塞入可公开发布的素材包。

最终以实际渲染做[设计复核](design-review.md)，不能以模型声称“高审美”替代检查。
