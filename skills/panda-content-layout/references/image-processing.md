# 需要时才进行图片处理

先判断版面能否直接使用原图。保持源图、派生图和生成图的关系，记录原件ID、处理范围、任务版本与前后对照。遵循用户实际授权；不要仅因具备生图工具就给每张图加工。

裁切、缩放和适度色调处理按项目范围执行；主体、空间轴线与必需标注必须检查。抠图、清理、扩图用明确区域与保留项约束实际可用工具，失败时不要假称已完成。

新增人物、家具、材料或改变建筑会改变内容，按明确编辑/概念生成授权执行；没有授权时记录建议。概念图和实际项目照片分开标识，不把生成物当现场证据。

Logo、精确图纸和必须保持的标识使用原件及可核对变换，不自由生成重画。成品文字与Logo尽量保持原生独立对象；图片处理不等于把整页PPT做成不可编辑图。

检查前后主体、边缘、透视、文字、颜色和真实性；高像素文件不等于低清源图获得了可靠细节。图片派生变化只使相关页面失效，不自动重做全部项目。
