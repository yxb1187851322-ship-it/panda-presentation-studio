# 杂志图片分支

从已选内容与素材关系生成单张封面或系列图片。数量、画幅和全部使用要求来自本次任务，不固定四张，不将所有图拼在一张。封面少字不能作为全部文档内容的删减理由。

保留原图主体、空间轴线、人物肢体、产品标签和水印。图片与文字独立组织，母版可采用可用的HTML/CSS、SVG或原生设计文件。常规排版不重绘照片，新增画面需匹配用户授权并标明合成性质。

用户未另定尺寸时，沿用数字图片默认：3:4为2160×2880 PNG，16:9为3840×2160 PNG，其他比例按用途确定。印刷任务需另外确认成品尺寸、出血、色彩与输出要求；不能以数字图片默认像素承诺印刷适用。

正式文件从原图和文字母版渲染，不放大旧截图冒充高清重制。核对真实输出像素、解码与裁切后的有效源像素。低清图可缩小图窗或说明限制；AI推测细节不是原摄影细节恢复。

导出逐张PNG和明确标注的总览；检查100%局部、文字边缘、对齐、相切、图注与系列节奏。若使用HTML截图工具，仍需核验CSS背景图、SVG内位图、字体字形与溢出，不能只检查img元素。

交付逐张成品、可编辑母版、必要素材、覆盖表和打开说明。用户要求整组时完成整组候选，除真实关键缺口外不机械增加确认阶段。
